# Phase 13 — Final unseen evaluation

Status: **completed once, sealed, and closed to post-test tuning**

## Evaluation protocol

The dedicated Final Test runner completed one run on `2026-09-06` under the following controls:

1. Verified the existing dataset seal for four control files and 32 invoice files.
2. Froze the runtime code, verified KB, schemas, requirements, Phase 12 baseline, and Final Test seal before inference.
3. Created a single-use run state before opening the test for inference.
4. Ran the agent on all 32 invoices using only `invoice_path` and `validation_date`.
5. Loaded Final Test ground truth only after inference completed for the full split.
6. Scored detection, retrieval, grounding, correction, re-validation, and tool reliability.
7. Wrote and cryptographically sealed the freeze manifest and final result files.
8. Marked post-test tuning as prohibited.

The pre-run project test suite passed **129/129** tests. Later regression suites may verify the sealed files but do not rerun Final Test inference.

## Error analysis

There were no detection, retrieval, grounding-contract, correction, integrity, or tool-selection errors in the Final Test run. Consequently, the machine-readable error records are empty.

The perfect score must be interpreted within the benchmark design. The Final Test was unseen during development, but it was generated by the same deterministic schema, frozen profile, operator family, and rule definitions as Development and Validation. The result establishes consistency within the declared synthetic benchmark; it does not establish robustness to arbitrary production invoices or complete ZATCA compliance.

## Limitations

- The benchmark covers eight selected rules and one frozen Standard Tax Invoice profile only.
- All data are synthetic and generated by the project pipeline.
- No live LLM provider was used in the final run.
- Grounding was measured through an exact evidence contract, not human semantic adjudication.
- The system does not submit, clear, report, sign, certify, or obtain approval for invoices from ZATCA.
- No result may be described as “ZATCA Approved,” “Officially Compliant,” or “ZATCA Certified.”

The permitted conclusion is:

**Passed the selected checks implemented in this proof of concept.**

## Exit decision

Phase 13 is complete and frozen. Phase 14 may build the Streamlit demo around the frozen pipeline, but must not change the evaluated validation logic or reinterpret the final metrics.
